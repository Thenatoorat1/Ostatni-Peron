# Ostatni Peron

Izometryczne RPG w przeglądarce w klimacie starego Fallouta: powojenna Europa, metro, pustkowia i lasy.

Zagraj: https://thenatoorat1.github.io/Ostatni-Peron/

## Co jest w repo

- `index.html` – aktualne demo (prerenderowana grafika, realna skala, niszczenie i odstrzeliwanie kończyn).
- `assets/` – sprite'y: świat (`world_*`, `ground.png`) i postacie (`chars_*`). Pliki `*_geo.png` to mapy głębokości i wysokości.
- `demos/` – wcześniejsze wersje: `woksele.html` (świat z wokseli) i `sprite-proceduralne.html` (sprite'y generowane kodem).
- `tools/` – skrypty: `render_char.py` (render postaci w Blenderze, bpy), `pack_chars.py` (atlas postaci), `build_world.py` (wycinanie i mapy głębokości dla obrazów świata).

## Sterowanie

WASD ruch, mysz celowanie i strzał, 1–4 broń, Spacja zwolnione tempo, T atak wrogów, V podgląd sprite'ów, R od nowa.
